## 1. 当前版本定位

Naviora 当前版本已经具备一个可内测、可上线迭代的 `Smart Entry / Smart QR` 产品雏形，核心闭环包括：

1. 用户可以完成注册、登录、密码重置与账户安全设置。
2. 用户可以创建、编辑、归档、恢复和查看智能入口。
3. 用户可以通过 AI 对话快速生成入口草稿。
4. 用户可以为入口配置规则、二维码视觉样式、Logo、密码保护和草稿预览。
5. 外部访问者可以通过公开入口访问目标内容，并被规则路由到对应页面。
6. 系统可以记录访问、展示分析，并按套餐执行额度控制。
7. 用户可以集中管理图片与 PDF 等媒体资产。

## 3. 产品公开面与域名分层

### 3.1 当前公开面

当前产品按 `web / public` 两层发布面拆分：

- `www.naviora.link`
  主站、营销页、登录注册页、工作台、支付和分析 UI
- `go.naviora.link`
  统一公开访问层，负责解析公开 slug、执行规则命中、检查访问限制、承载公开内容并输出状态页

### 3.2 当前规则

- 入口 URL 统一走 `go`
- 内容 URL 也统一走 `go`
- 草稿 preview 链接统一走 `go`
- 当前路径约定：
  - `/l/:slug` = Web / Link
  - `/s/:slug` = WhatsApp / Social handoff
  - `/c/:slug` = Contact card / 电子名片

### 3.3 当前意义

这套结构已经为后续自定义域名、统一公开层缓存、内容载体扩展和模板系统演进打好了基础。

## 9. 智能入口创建与编辑

### 9.1 功能目标

让用户通过表单或 AI 对话完成一个智能入口的创建、确认和设计。

### 9.2 当前已实现能力

- 三步创建流
- 编辑已有入口
- AI 对话生成结构化草稿
- 支持 `web / whatsapp / vcard` 三类目标
- 支持规则模式配置
- 支持二维码视觉设计
- 支持保存草稿和正式发布
- 支持已发布入口重新编辑

### 9.3 三步流程

#### Step 1：Describe

- 用户用自然语言描述需求
- 或直接从快捷入口选择目标类型
- AI 可识别智能入口类型并生成草稿
- AI 支持补全 vCard 的社交媒体 / IM 字段

#### Step 2：Review

- 确认入口名称和默认目标
- 配置规则模式
- 配置高级设置：
  - 外部追踪
  - 密码访问
  - 到期时间
- 支持草稿校验

#### Step 3：Design

- 配置二维码样式
- 配置角框与中心样式
- 配置纠错等级
- 配置 Logo
- 实时二维码预览
- 保存草稿
- 生成二维码 / 正式发布

### 9.4 当前支持的目标类型

#### Web

- 默认目标为网页 URL
- URL 输入支持格式校验

#### WhatsApp

- 支持国家 / 区号
- 支持手机号
- 支持预填消息

#### vCard

- 支持姓名、电话、邮箱、公司、职位、网站
- 邮箱为选填
- 支持头像
- 支持社交媒体与 IM 渠道
- 支持公开名片页

### 9.5 当前支持的规则模式

- `none`
- `language`
- `region`
- `device`
- `param`
- `ab`

对应规则能力：

- `language`
  按语言命中不同 URL
- `region`
  按国家 / 地区命中不同 URL
- `device`
  按设备系统命中不同 URL
- `param`
  按 query 参数命中不同 URL
- `ab`
  A / B 两个变体按权重分流，总和必须为 `100`

### 9.6 当前表单规则

- URL 类字段支持格式校验
- 社交媒体字段按平台规则做输入提示与格式校验
- 微信按 `Account ID` 输入，不按 URL 处理
- 其他平台优先按 URL 处理
- 语言规则下拉支持按名称和语言代码搜索

### 9.7 当前边界

- 当前目标类型主要围绕网页、WhatsApp 和 vCard
- 更复杂的内容载体，例如邀请函、PDF 落地页、下载页、表单页等仍待扩展

## 10. 草稿 Preview、发布与密码访问

### 10.1 功能目标

让用户在正式发布前可以安全分享草稿预览，同时保证正式入口和草稿入口分离。

### 10.2 当前已实现能力

- 草稿进入设计步骤后自动保存
- 自动生成 preview token
- 草稿使用独立 preview link
- 正式发布后使用正式入口 URL
- 旧 preview token 自动失效
- 重新生成 preview link 时旧 token 失效
- preview token 带有效期
- 过期或无效 preview token 输出状态页
- preview token 有清理机制

### 10.3 当前规则

- 正式入口：
  - `go.naviora.link/l/:slug`
- 正式内容：
  - `go.naviora.link/c/:slug`
- 草稿 preview：
  - `go.naviora.link/preview/:token`

### 10.4 密码访问当前能力

- 入口支持开启密码保护
- 正式入口 `go` 层会先检查密码
- 草稿 preview 入口也会先检查密码
- 保存时会生成真实密码哈希，不再只是 UI 配置
- 编辑已有入口时可识别“已配置密码”

### 10.5 当前边界

- 当前密码门主要在统一公开层生效
- preview 与正式访问已经按单域名公开层统一
- 更细的公开访问令牌和内容级权限模型仍可后续增强

## 12. 公开入口访问与规则路由

### 12.1 功能目标

### 12.2 当前已实现能力

- 通过 slug 解析公开入口
- 根据规则模式选择命中目标
- 支持语言 / 地区 / 设备 / 参数 / A/B 路由

  - query 参数

- 地区匹配：
  - query 参数
  - Vercel 地理头
- 设备匹配：
  - query 参数

- A/B：
  - 通过稳定 hash 做分桶

### 12.4 当前状态页覆盖场景

- 需要输入密码

- 超限后不再继续跳转，改为展示升级提示状态页
